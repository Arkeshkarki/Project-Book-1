Number System and Boolean Logic

Introduction to Number Systems

A number system is a systematic way of representing numbers. In computing, different number systems are used for various purposes, from internal processing to data representation. The value of a digit in a positional number system depends on the digit itself, its position within the number, and the base (or radix) of the number system. The main positional number systems we will study are

Decimal Number System (Base-10)

It is the number system we use daily. It has 10 unique digits (0-9). Each position represents a power of 10.

Binary Number System (Base-2)

This system is the foundation of all digital computers. It uses only two digits: 0 and 1 (bits). Each position represents a power of 2. Computers use binary because electronic circuits have two stable states: ON (1) or OFF (0).

Octal Number System (Base-8)

This system uses eight digits (0-7). Each position represents a power of 8. Octal is often used as a shorthand to represent long binary numbers because three binary digits can be represented by a single octal digit.

Number System (Base-16)

This system uses sixteen digits (0-9 and A-F, where A represents 10, B represents 11, and so on, up to F for 15). Each position represents a power of 16. Hexadecimal is widely used in computer memory addressing and data representation due to its ability to represent four binary digits with a single hexadecimal digit. The base or radix of a number system indicates the total number of unique digits or symbols used in that system.

Number System Conversions

Converting numbers between different bases is a critical skill in computer science. Here, we'll cover the most common conversions.

1. Decimal to Binary, Octal, and Hexadecimal Conversion

To convert a decimal number to another base, we use the division-remainder method. Divide the decimal number by the target base repeatedly, noting the remainders at each step. The remainders, read from bottom to top, form the number in the new base.

2. Binary, Octal, and Hexadecimal to Decimal Conversion

To convert a number from any base to decimal, multiply each digit by its corresponding positional weight (base raised to the power of its position) and sum the results. Positions are counted from right to left, starting with 0.

3. Binary to Octal and Hexadecimal Conversion

Binary to Octal: Group binary digits in sets of three from right to left, adding leading zeros if necessary. Convert each group of three binary digits into its equivalent octal digit.
Binary to Hexadecimal: Group binary digits in sets of four from right to left, adding leading zeros if necessary. Convert each group of four binary digits into its equivalent hexadecimal digit.

Introduction to Boolean Values, Truth Table, Boolean Expression, and Boolean Function

Boolean Algebra:

Named after George Boole, Boolean algebra is a branch of algebra in which the values of the variables are the truth values, true and false, usually denoted 1 and 0 respectively. It is fundamental to the design of digital electronic circuits.

Boolean Values:

These are the two possible values in Boolean algebra: True (represented as 1) and False (represented as 0). These correspond to the ON and OFF states of electronic switches.

Truth Table:

A truth table is a mathematical table used in logic, specifically in Boolean algebra, to compute the functional values of logical expressions for each combination of input values. It lists all possible input combinations and the corresponding output for a given logical operation or expression.

Boolean Expression:

A Boolean expression is an expression formed by combining Boolean variables (which can take values 0 or 1), logical operators (AND, OR, NOT), parentheses, and an equals sign. For example, A + B' is a Boolean expression.

Boolean Function:

A Boolean function, also known as a logic function, is an expression that produces a binary output (0 or 1) based on binary inputs. It defines the relationship between input variables and the output of a logic circuit. For a given set of binary variable values, the function can evaluate to either 0 or 1.

Logic Gates

Logic gates are the basic building blocks of any digital system. They are electronic circuits that perform basic logical functions based on one or more binary inputs and produce a single binary output. Each gate implements a specific Boolean operation. Here are the primary logic gates with their symbols, truth tables, and Boolean expressions:

1. AND Gate

The AND gate produces a HIGH output (1) only if all its inputs are HIGH (1). Otherwise, the output is LOW (0). It performs logical multiplication.

2. OR Gate

The OR gate produces a HIGH output (1) if at least one of its inputs is HIGH (1). The output is LOW (0) only if all inputs are LOW (0). It performs logical addition.

3. NOT Gate (Inverter)

The NOT gate has only one input and one output. It inverts the input; if the input is HIGH (1), the output is LOW (0), and vice versa.

4. NAND Gate (NOT-AND)

The NAND gate is a combination of an AND gate and a NOT gate. Its output is LOW (0) only if all inputs are HIGH (1); otherwise, the output is HIGH (1).

5. NOR Gate (NOT-OR)

The NOR gate is a combination of an OR gate and a NOT gate. Its output is HIGH (1) only if all inputs are LOW (0); otherwise, the output is LOW (0).

6. XOR Gate (Exclusive-OR)

The XOR gate produces a HIGH output (1) if an odd number of inputs are HIGH (1). For two inputs, it produces a HIGH output if the inputs are different.

7. XNOR Gate (Exclusive-NOR)

The XNOR gate is the complement of the XOR gate. It produces a HIGH output (1) if an even number of inputs are HIGH (1). For two inputs, it produces a HIGH output if the inputs are the same.

Laws of Boolean Algebra

Boolean algebra has several laws that help simplify Boolean expressions and design efficient logic circuits. These laws are similar to algebraic laws but apply to binary variables and logical operations. Let A, B, and C be Boolean variables (0 or 1).

1. Commutative Laws

These laws state that the order of operands does not affect the result. AND: A ⋅ B = B ⋅ A OR: A + B = B + A

2. Associative Laws

These laws state that the grouping of operands does not affect the result when performing the same operation multiple times. AND: (A ⋅ B) ⋅ C = A ⋅ (B ⋅ C) OR: (A + B) + C = A + (B + C)

3. Distributive Laws

These laws describe how operations distribute over each other. AND over OR: A ⋅ (B + C) = (A ⋅ B) + (A ⋅ C) OR over AND: A + (B ⋅ C) = (A + B) ⋅ (A + C)

4. De Morgan's Laws

De Morgan's laws are crucial for simplifying expressions involving complements (NOT operations). Law 1: (A + B)' = A' ⋅ B' (The complement of a sum is the product of the complements.)
Law 2: (A ⋅ B)' = A' + B' (The complement of a product is the sum of the complements.) Other important laws and identities:

Identity Law:

  • A + 0 = A
  • A ⋅ 1 = A

    • Null Law:

  • A + 1 = 1
  • A ⋅ 0 = 0

    • Idempotent Law:

    A + A = A
    A ⋅ A = A

    Complement Law:

    A + A' = 1
    A ⋅ A' = 0

    Involution Law (Double Complement):

    (A')' = A

    Absorption Law:

    A + (A ⋅ B) = A
    A ⋅ (A + B) = A

    Logic Circuits

    Logic circuits (or digital circuits) are physical implementations of Boolean functions using logic gates. They are the fundamental components of digital electronics, such as microprocessors, memory, and other digital devices. Designing a logic circuit involves converting a Boolean expression into a diagram using standard logic gate symbols. Example: Draw a logic circuit for the Boolean expression Y = A ⋅ B + C'. Here's how to break it down:
  • Identify the inputs: A, B, C.
  • Identify the operations: AND (A ⋅ B), NOT (C'), OR (result of A ⋅ B and C').
  • Draw the gates in sequence:
    • An AND gate for A and B. A NOT gate for C. An OR gate for the output of the AND gate and the output of the NOT gate.
