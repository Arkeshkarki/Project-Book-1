Number System and Boolean Logic

Introduction to Number Systems

A number system is a systematic way of representing numbers. In computing, different number systems are used for various purposes, from internal processing to data representation. The value of a digit in a positional number system depends on the digit itself, its position within the number, and the base (or radix) of the number system. The main positional number systems we will study are

Decimal Number System (Base-10)

It is the number system we use daily. It has 10 unique digits (0-9). Each position represents a power of 10.

Binary Number System (Base-2)

This system is the foundation of all digital computers. It uses only two digits: 0 and 1 (bits). Each position represents a power of 2. Computers use binary because electronic circuits have two stable states: ON (1) or OFF (0).

Octal Number System (Base-8)

This system uses eight digits (0-7). Each position represents a power of 8. Octal is often used as a shorthand to represent long binary numbers because three binary digits can be represented by a single octal digit.

Number System (Base-16)

This system uses sixteen digits (0-9 and A-F, where A represents 10, B represents 11, and so on, up to F for 15). Each position represents a power of 16. Hexadecimal is widely used in computer memory addressing and data representation due to its ability to represent four binary digits with a single hexadecimal digit. The base or radix of a number system indicates the total number of unique digits or symbols used in that system.

Number System Conversions

Converting numbers between different bases is a critical skill in computer science. Here, we'll cover the most common conversions.

1. Decimal to Binary, Octal, and Hexadecimal Conversion

To convert a decimal number to another base, we use the division-remainder method. Divide the decimal number by the target base repeatedly, noting the remainders at each step. The remainders, read from bottom to top, form the number in the new base.
