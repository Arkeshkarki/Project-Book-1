Problem Solving and Algorithm

An algorithm is a step-by-step procedure to solve a problem.

Example Algorithm: To add two numbers

  1. Start
  2. Read two numbers A and B
  3. Calculate SUM = A + B
  4. Display SUM
  5. Stop

Flowchart

A flowchart is a diagrammatic representation of an algorithm using symbols.

Example: Flowchart for adding two numbers

  • Oval: Start/Stop
  • Parallelogram: Input/Output
  • Rectangle: Process

Introduction to Programming Languages

Programming languages are used to write instructions for computers. Examples: C, C++, Java, Python.

Structure of C Programming

A simple C program has:

  • Header files
  • Main function
  • Statements

Example Program:

#include <stdio.h>

int main() {
    int a, b, sum;
    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);
    sum = a + b;
    printf("Sum = %d", sum);
    return 0;
}

Data Types, Variables, Operators

  • Data Types: int, float, char, double
  • Variables: Names used to store data (e.g., int age = 16;)
  • Operators: +, -, *, /, %

Input and Output Statements

  • Input: scanf()
  • Output: printf()

Example:

#include <stdio.h>

int main() {
    float radius, area;
    printf("Enter radius: ");
    scanf("%f", &radius);
    area = 3.14 * radius * radius;
    printf("Area of circle = %.2f", area);
    return 0;
}
